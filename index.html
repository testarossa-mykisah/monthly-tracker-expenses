Data kamu, di HP kamu.

0 akun 0 server 0 rupiah

Tidak ada yang didaftarkan dan tidak ada data yang dikirim ke mana-mana. Semua catatanmu tersimpan di browser HP kamu sendiri — kami tidak pernah melihatnya, karena memang tidak ada tempat untuk melihatnya.

Pasang di HP dalam semenit.

iPhone

  1. Buka aplikasi di Safari.
  2. Ketuk tombol Share di bawah layar.
  3. Pilih Add to Home Screen, lalu Add.

Ikon aplikasi muncul di layar utama dan bisa dibuka seperti aplikasi biasa.

Android

  1. Buka aplikasi di Chrome.
  2. Ketuk menu ⋮ di kanan atas.
  3. Pilih Install app atau Tambahkan ke layar utama.

Setelah terpasang, aplikasi bisa dibuka offline.

Yang sering ditanya.

Apakah gratis?

Ya, sepenuhnya. Tidak ada biaya, tidak ada langganan, tidak ada fitur yang dikunci.

Apakah data saya aman?

Data tersimpan di HP kamu sendiri, di penyimpanan browser. Tidak ada akun dan tidak ada server, jadi tidak ada pihak lain yang bisa mengaksesnya.

Bisa pindah HP?

Bisa. Di HP lama, buka Data & Cadangan lalu Export Backup. Di HP baru, buka aplikasi lalu Import file tersebut — semua dompet dan riwayat ikut pindah.

Apakah butuh akun?

Tidak. Buka aplikasi, langsung catat. Tidak ada email, kata sandi, atau proses daftar.
